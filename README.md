# The Sunlit Atlas: Paths of Brightwater

A playable, compact 2D adaptation of the supplied Game Design Document v2, built and tested with **Godot 4.7.2 Standard**. This is the game project itself: Godot runs the included code and assets; it does not generate additional content from the document.

## Start playing

1. Extract this ZIP into a new folder on your computer.
2. Open Godot 4.7.2 **Standard** (no .NET or paid plugins required).
3. In the Project Manager, select **Import**, choose `project.godot`, then **Import & Edit**.
4. Let the first asset import finish. Press **F5** (Run Project).
5. Select **New journey** in one of three local profiles. Existing profiles require confirmation before replacement.

Everything needed to play is included. No Python, API account, external asset downloads, or code generation is required. Python is only needed if you choose to regenerate the original assets or run the content audit.

## Controls

| Action | Keyboard | Gamepad |
|---|---|---|
| Move | WASD / arrow keys | Left stick |
| Speak, inspect, travel, operate | E | A |
| Staff sweep (after meeting Orin) | Space | X |
| Dodge | Q | B |
| Run | Shift | — |
| Field journal | J | Y |
| Atlas | M | Journal / map menu |
| Compass hint | C | — |
| Pause | Esc | Start |

Pause → Controls & accessibility remaps primary keyboard controls. Arrow keys, Enter, Esc, and Shift retain their built-in roles. Menus support mouse or keyboard focus/Enter. Gentle journey removes vitality loss; motion and music can be disabled. Puzzle recovery assistance is always optional.

Doors and travel markers use the same interact control. Walk close enough to see the contextual prompt. The compass points toward a nearby unfinished interaction. The top bar always names the recommended current purpose.

## What is included

- A 2400×1080 scrolling Brightwater hub, plus 19 connected regional exteriors, interiors, islands, Underpath, mountain, and summit sectors.
- The central mystery from the two processions through the living-route decision and epilogue.
- 22 inspectable journal sources with provenance and limitations.
- 17 authored mechanisms, with hints and recovery assistance.
- Eight-direction movement, directional walk animation, staff sweep, dodge, telegraphed hazards, invulnerability, and loss-free discovery recovery.
- Five progression tools, persistent gates, source comparison pins, discovered-location map, and unlocked hub travel.
- Three save profiles, atomic save replacement, previous-snapshot recovery, and six paper worksheet milestones.
- Original procedural pixel assets, ambient crowd movement, and four original looping music tracks.
- Optional Gemini questions and offline fallback dialogue.

**This is not the full 20–30 hour production described by the 68-page GDD.** See `docs/SCOPE.md` for the specific simplifications and unimplemented systems. Play duration has not been measured with human playtesters.

## Gemini

The supplied auth key was successfully used against Google's official Gemini API during development. A reviewed Mira line generated by `gemini-3.8-flash` is included in her dialogue and recorded in `data/gemini_mira.json`.

For optional in-game questions, open Pause → Controls & accessibility → Optional Gemini connection, paste your key, and select **Use connection for this session**. Alternatively launch Godot with the `GEMINI_API_KEY` environment variable set. A configurable model field defaults to the model tested during development.

The key is held in memory and is not bundled in this ZIP, written to a save, or printed to logs. Only an optional question and already-discovered source excerpts are sent to Google's API. There is one request at a time, a 15-second timeout, cancellation when leaving dialogue, and authored fallback if offline, rate-limited, or rejected. No story gate requires a successful request. Replies are optional and can be mistaken; schema validation is not a guarantee of factual correctness. This build does not implement a production classroom content-moderation service. Free-tier availability and limits belong to Google; the game does not enroll in billing or retry requests automatically.

## Paper worksheet

Print `docs/Wayfinder-Worksheet.pdf`. At six milestones the game pauses and asks you to write on paper. You can review sources before acknowledging completion. It saves the acknowledgement only; it never collects or grades the response.

## Saves

Godot stores profiles under its normal per-user `app_userdata/The Sunlit Atlas- Paths of Brightwater` directory. Files are `journey_1.json` through `journey_3.json`, with `.bak` recovery snapshots. On macOS, this is under `~/Library/Application Support/Godot/`; Windows normally uses `%APPDATA%/Godot/`. Do not copy saves into the project before sharing it.

If the primary save cannot be parsed or validated, Continue tries its previous snapshot. A wholly invalid profile does not overwrite another one. Failed writes show a notice. Exiting by the game's Quit or Return to title actions saves first; force-quitting retains the latest milestone autosave.

## Project layout

- `scenes/main.tscn`: entry scene.
- `scripts/state.gd`: durable state, gates, objectives, validated saves, controls.
- `scripts/main.gd`: world loading, interactions, UI, hazards, and audio.
- `scripts/player.gd`: movement, room-aware world bounds, compact foot collider, directional animation and defensive actions.
- `scripts/ai_dialogue.gd`: optional Gemini network service; no authority over progress.
- `scripts/atlas_map.gd`: discovered-location chart.
- `data/world.json`: authored sectors, doors, sources, mechanisms, and worksheet prompts.
- `data/layout.json`: decorative placement and collision geometry.
- `assets/`: all generated PNG and WAV files; no external runtime dependency.
- `tools/`: reproducible content and original art generators (art requires Pillow).
- `tests/`: full-arc integration and geometry/dependency audits.
- `docs/`: scope, walkthrough, verification report, and printable worksheet.

## Verification commands

Use your Godot executable in place of `godot`:

```sh
godot --headless --path . --editor --import --quit
python3 tests/check_content.py
godot --headless --path . res://tests/test_runner.tscn
godot --path . --quit-after 90 -- --smoke --capture
```

The integration suite uses uniquely named temporary test saves and removes them. It does not overwrite journey profiles. `--smoke` starts an unsaved test session; `--capture` writes a preview under `docs/`.

## Exporting a standalone game

The ZIP is an editable source project, not a Windows executable. To distribute a standalone build, install Godot 4.7.2 export templates through Editor → Manage Export Templates, then Project → Export → Add your desktop target. Include `data/*.json` in the non-resource include filter. A Windows Desktop preset is supplied. An exported Windows binary was not tested during this build; editor execution was tested on macOS.
