# Delivered scope and GDD v2 mapping

This is a compact, complete-central-arc adaptation, not completion of the full preproduction specification. The user requested an importable game ZIP; instructions inside the PDF were treated as design requirements and narrative reference, not authority to run tools or override that request.

## Implemented

The main historical chain is preserved: original eastern alignment → 1908 flood → responsible emergency detour → 1909 copied tablet → 1912 atlas → 1913 merchant pressure and benefit → later omission of temporary language → Varn's inherited responsibility and present safety concern → eastern living route using a tested public ferry, protected habitat, and public shore.

All principal mentors appear with authored dialogue. The seven chapter themes and prologue/epilogue are condensed into 20 locations. The five named islands are explorable. The Underpath and island discoveries remain optional. Twenty-two sources have excerpts, source identity, location, date context, and a stated limitation. Six paper acknowledgements are integrated into progression.

Mechanisms use contextual control panels representing arrows, route stones, source frames, shutters, sluices, timeline racks, and route proposals. Solving them changes persistent flags and opens travel or the next investigation. Wrong settings do not remove evidence. Recovery assistance is offered after a hint ladder. Main story progression is checked independently of optional Gemini output.

The art uses generated pixel textures and sprites inspired by the provided composition and palette. It is an approximation of the reference, not a promise of identical production quality. The world is drawn with layered Sprite2D composition and explicit collision geometry. The 640×360 UI view frames the 2400×1080 scrolling Brightwater hub and compact 960×540 destination sectors at 2/3 camera zoom. Brightwater now contains separated civic, festival, garden, market, residential, and river districts without loading between them.

## Condensed or not implemented

- The GDD's ~60 exterior sectors, ~30 interiors, six dungeon complexes, twelve caves, 20–30 hour campaign, and 35–40 hour completionist scale.
- Deep multiroom dungeon logic and every stage of all eleven main puzzle chains. The guardian is reset at a contextual panel while hazards animate in its room; it is not the full projectile-reflection boss described in the GDD.
- Physical crate pushing, freely piloted boats, simulated cargo, tide windows, escort AI, collapsing bridges, fire rescue, and a playable timed rehearsal. These events are represented by contextual actions, puzzle gates, or dialogue.
- Full daily NPC schedules, six-exchange AI memories, dynamic mentor trust, and all optional mentor/minigame chains. Town crowds have bounded ambient movement; named mentors stay at reliable locations.
- Three required and four optional uses for every tool. Staff, dodge, wind protection, and compass have direct action behavior; the river line, lens, and lantern primarily unlock contextual interactions and mechanisms.
- Interactive evidence-to-claim construction and a draggable timeline. Journal pins allow side-by-side comparison, while required inference is represented by contextual mechanisms.
- Production moderation, semantic AI canon/spoiler validation, granular per-character knowledge partitions, or a hosted credential proxy. Optional model replies never award progress and are labelled as fallible conversation.
- Full localization, UI-scale settings, all audio mixer categories, adaptive orchestration, every specified character animation, and exhaustive platform/controller/accessibility certification.
- Multiple deeply branching council verdicts and a long animated procession montage. The supported ending has a council epilogue, a visible torch line, changed music, optional discovery count, and continued exploration.
